Pacote: pedido
==============

Atende US05, US06, US07, US08. Modulo mais complexo - deixe por ultimo.

Organize em sub-pacotes:
  pedido/
  ├── entity/       Pedido.java, ItemPedido.java, StatusPedido.java (enum)
  ├── repository/   PedidoRepository.java
  ├── dto/          CarrinhoRequest.java, AdicionarItemRequest.java,
  │                 CriarPedidoRequest.java, PedidoResponse.java
  ├── service/      CarrinhoService.java, PedidoService.java
  └── controller/   CarrinhoController.java, PedidoController.java

CONCEITO 1: Enum como coluna no banco
-------------------------------------
StatusPedido pode ser: AGUARDANDO_PAGAMENTO, PAGO, PREPARANDO, ENVIADO, ENTREGUE, CANCELADO

Na entidade Pedido:
  @Enumerated(EnumType.STRING)
  @Column(nullable = false)
  private StatusPedido status;

Use STRING (nao ORDINAL), porque ORDINAL salva o indice numerico e quebra
se voce reordenar os valores do enum.

CONCEITO 2: Relacionamento 1:N com cascade
------------------------------------------
Um pedido tem muitos itens. Quando salvar o pedido, salve os itens junto:

  @OneToMany(mappedBy = "pedido", cascade = CascadeType.ALL, orphanRemoval = true)
  private List<ItemPedido> itens = new ArrayList<>();

CONCEITO 3: Carrinho - onde guardar?
------------------------------------
Existem 3 abordagens. Escolha uma:

(a) Em memoria (Map<usuarioId, Carrinho>)        -> Mais simples, perde tudo se reiniciar app
(b) No banco (tabela carrinho + item_carrinho)   -> Mais complexo, persiste
(c) Frontend (localStorage)                       -> Recomendado para MVP

Para aprendizado, sugiro comecar com (a) - usar @Service com um Map<Long, Carrinho>
e depois evoluir para (b).

CONCEITO 4: Autorizacao por dono
--------------------------------
US08: usuario so pode ver os PROPRIOS pedidos.

No service:
  public List<PedidoResponse> meusPedidos(Long usuarioId) {
      return repository.findByUsuarioId(usuarioId)...
  }

No controller, pegue o usuario do contexto:
  @GetMapping
  public List<PedidoResponse> meusPedidos(@AuthenticationPrincipal Usuario logado) {
      return service.meusPedidos(logado.getId());
  }

Endpoints sugeridos:
  POST   /api/v1/carrinho/itens                (US05 adicionar)
  GET    /api/v1/carrinho                       (US05 ver)
  PUT    /api/v1/carrinho/itens/{marmitaId}     (US05 alterar quantidade)
  DELETE /api/v1/carrinho/itens/{marmitaId}     (US05 remover)
  POST   /api/v1/pedidos                        (US06 finalizar)
  GET    /api/v1/pedidos/{id}                   (US07 status)
  GET    /api/v1/pedidos                        (US08 historico)
